# Установка

Требуется Python 3.10 или новее. Для Windows, Linux и macOS используется один пакет Python; низкоуровневые функции зависят от прав и установленных драйверов ОС.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[test]'
.venv/bin/python -m pytest -q
.venv/bin/python -m viruswall gui
```

Windows PowerShell:

```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -e ".[test]"
.venv\Scripts\python.exe -m pytest -q
.venv\Scripts\python.exe -m viruswall gui
```

Зависимости: `psutil` для процессов/соединений, `scapy` для ограниченного пассивного захвата пакетов и разбора PCAP, `cryptography` для AES-256-GCM карантина и подписей обновлений (Ed25519), `PySide6-Essentials` для desktop-интерфейса, `watchdog` для событий файловой системы в реальном времени (inotify/ReadDirectoryChangesW/kqueue), `pytest` только для тестов. Для запуска `gui` нужна графическая сессия ОС; сервер и браузер не требуются.

Scapy может потребовать Npcap на Windows или права на захват пакетов в Linux/macOS. Без них остаются доступны сканирование файлов, процессы и список соединений в пределах разрешений ОС. Приложение не запрашивает автоматически повышение прав. В ограниченной среде доступ к списку процессов и сокетов может быть запрещён; интерфейс покажет ошибку и продолжит работать. Если `watchdog` отсутствует, защита каталога автоматически переходит в резервный режим опроса метаданных.

Проверку работоспособности выполните командой `python -m viruswall doctor`: она проверит зависимости, права каталога данных, целостность хеш-цепочки журнала, ключ карантина, состояние базы сигнатур и свободное место. Данные по умолчанию создаются с правами 0700/0600 на Unix. Повторный запуск приложения для того же каталога данных блокируется lock-файлом (самозащита от параллельных экземпляров).

Для безопасного теста задавайте отдельный каталог данных: `python -m viruswall --data-dir ./demo-data status`. Не храните этот каталог внутри сканируемой папки, чтобы избежать повторного анализа собственных файлов; приложение исключает его автоматически.
