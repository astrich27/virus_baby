# Установка

Требуется Python 3.10 или новее. Для Windows, Linux и macOS используется один пакет Python; низкоуровневые функции зависят от прав и установленных драйверов ОС.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[test]'
.venv/bin/python -m pytest -q
.venv/bin/python -m viruswall gui
```

Windows PowerShell:

```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -e ".[test]"
.venv\Scripts\python.exe -m pytest -q
.venv\Scripts\python.exe -m viruswall gui
```

Зависимости: `psutil` для процессов/соединений, `scapy` для ограниченного пассивного захвата пакетов, `cryptography` для AES-256-GCM карантина, `PySide6-Essentials` для desktop-интерфейса, `pytest` только для тестов. Мониторинг файлов использует стандартную библиотеку Python, потому дополнительный `watchdog` не требуется. Для запуска `gui` нужна графическая сессия ОС; сервер и браузер не требуются.

Scapy может потребовать Npcap на Windows или права на захват пакетов в Linux/macOS. Без них остаются доступны сканирование файлов, процессы и список соединений в пределах разрешений ОС. Приложение не запрашивает автоматически повышение прав. В ограниченной среде доступ к списку процессов и сокетов может быть запрещён; интерфейс покажет ошибку и продолжит работать.

Для безопасного теста задавайте отдельный каталог данных: `python -m viruswall --data-dir ./demo-data status`. Не храните этот каталог внутри сканируемой папки, чтобы избежать повторного анализа собственных файлов; приложение исключает его автоматически.
