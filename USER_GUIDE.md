# Руководство пользователя

Запустите `python -m viruswall gui`. Откроется отдельное окно VirusWall. Вкладка «Главная» показывает включённые модули, число сигнатур, объекты карантина и последние обнаружения. Программа работает только на этой рабочей станции.

Во вкладке «Сканирование» выберите файл или каталог. Проверка запускается в отдельном потоке, чтобы окно оставалось отзывчивым. Для каталога выполняется рекурсивная проверка. Результат содержит путь, SHA-256, статус, название угрозы и время. `clean` означает, что текущие правила ничего не нашли; это не гарантия безопасности. `excluded` и `skipped_symlink` означают пропуск. `error` означает, что файл не удалось проверить. Таблица показывает первые 500 результатов, полный отчёт со всеми файлами можно экспортировать в JSON или CSV.

«Эвристика» показывает правила, сработавшие при последней проверке. Чувствительность меняется в «Настройках»: чем выше значение, тем больше подозрительных сочетаний будут отмечены. Вкладки «Процессы» и «Сеть» показывают доступные ОС данные. Пока окно открыто, процессы и соединения проверяются каждые две секунды; кнопки обновляют таблицы вручную. Первый снимок служит базой. Захват пакетов запускается отдельной кнопкой для выбранного интерфейса и ограничен по времени.

«Журнал» показывает обнаружения и действия; записи можно фильтровать по источнику и уровню. В «Карантине» можно выбрать файл и поместить его копию после подтверждения. По умолчанию оригинал остаётся на месте. Чтобы изолировать угрозу, отдельно отметьте «Изолировать»: исходный файл будет убран после безопасного сохранения шифрованной копии. Восстановление не перезаписывает существующий файл: если исходный путь занят, окно предложит выбрать новый. В CLI то же действие выполняется `quarantine put PATH --yes --remove-original`.

«Настройки» позволяют включить/отключить модуль, изменить чувствительность, добавить каталог в исключения, управлять тестовыми сигнатурами и запустить мониторинг выбранного каталога. При закрытии окна мониторинг прекращается. Сетевые пороги и списки адресов задаются в `config.json` в поле `network_rules`, например `{"max_connections": 30, "suspicious_ips": ["203.0.113.10"]}`; после изменения перезапустите приложение.

Для ручной проверки из терминала используйте `python -m viruswall scan PATH --report report.json`. Формат CSV доступен по расширению `.csv`. Отчёт о ложных срабатываниях и проценте обнаружения рассчитывается только при наличии размеченного тестового набора через API `evaluate`.
