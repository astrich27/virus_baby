# Руководство пользователя

Запустите `python -m viruswall gui`. Откроется отдельное окно VirusWall с восемью вкладками. «Главная» показывает включённые модули, число сигнатур и шаблонов, версию движка и базы, объекты карантина и последние обнаружения; приостановленные (ограниченные ОС) модули отображаются отдельно. Программа работает только на этой рабочей станции; повторный запуск с тем же каталогом данных запрещён (самозащита от параллельных экземпляров).

**Сканирование**: выберите файл или каталог; проверка идёт в отдельном потоке. Результат содержит путь, SHA-256, статус (`clean`, `threat`, `suspicious`, `excluded`, `skipped_symlink`, `error`), название угрозы и время. Обнаружение возможно по SHA-256, MD5 или байтовому шаблону. Отчёт экспортируется в JSON, CSV или **TXT** (кнопка и параметр `--report`).

**Эвристика** показывает сработавшие правила; чувствительность меняется в «Настройках». **Процессы** и **Сеть** отражают данные ОС: процессы обновляются каждые 2 секунды, соединения — по кнопке; новый процесс сопоставляется с поведенческими шаблонами из конфигурации. Захват пакетов — кнопка для выбранного интерфейса; сохранённый ранее файл захвата разбирается командой `pcap capture.pcap`.

**Наблюдение**: кнопка стартует защиту выбранного каталога в реальном времени на событиях ОС (при недоступности watchdog — резервный опрос). Политика реагирования берётся из `config.json` (`realtime.action_on_detection`): `observe` — только журнал; `notify` — журнал и уведомления; `quarantine` — автоматическая изоляция угрозы, требует режима «на взводе» (CLI `--arm` или включение политики в конфигурации). В интерфейсе отображаются backend, политика и задержка реакции.

**Журнал**: записи с фильтрами по типу/источнику/уровню; для находок уровня `high` показывает системные уведомления. Целостность хеш-цепочки проверяется командой `events --verify` или в API `journal.verify()`.

**Карантин**: копия файла шифруется AES-256-GCM после подтверждения; оригинал удаляется только при отдельной отметке «Изолировать». Действуют лимиты из конфигурации (`quarantine.max_total_bytes`, `max_items`, `retention_days`); при исчерпании лимита помещение приостанавливается с событием. Восстановление не перезаписывает существующие файлы и после восстановления запускает повторное сканирование. Удаление объекта выполняет перезапись содержимого случайными байтами перед удалением. Обслуживание по сроку хранения — `quarantine purge --yes`.

**Настройки**: модули вкл/выкл, чувствительность, исключения (пути и маски `*.pdf.exe`), тестовые сигнатуры, защита каталога. Команда `doctor` выполняет самотестирование. Пример CLI-команд:

```bash
python -m viruswall scan PATH --report report.txt   # отчёт TXT
python -m viruswall pcap path/capture.pcap          # разбор потока
python -m viruswall update update.json              # подписанная база
python -m viruswall quarantine delete <id> --yes    # безопасное удаление
python -m viruswall events --verify                 # целостность журнала
```

Показатели доли ложных срабатываний и процента обнаружения рассчитываются только для размеченного тестового набора через `evaluate`; подробности см. в [TESTING.md](TESTING.md).
